# 075. React Router, sem biblioteca de estado ou de requisições por enquanto

- **Data:** 2026-10-02
- **Status:** [substituída por 066](066-tanstack-query-no-painel.md)

## Contexto

Uma página pública só pede um `fetch`; TanStack Query entra se o painel precisar de cache.

## Decisão

React Router, sem biblioteca de estado ou de requisições por enquanto.

Alternativas descartadas: RULES: nada "para o futuro".

## Consequência

Substituída no mesmo dia: o painel passou a usar TanStack Query (ver acima).
