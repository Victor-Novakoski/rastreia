# 076. Fonte do sistema e ícones SVG próprios

- **Data:** 2026-10-02
- **Status:** ativa

## Contexto

Página pública abre rápido em rede ruim e não depende de CDN externa, o que facilita a CSP.

## Decisão

Fonte do sistema e ícones SVG próprios.

Alternativas descartadas: Inter via Google Fonts, lucide-react.

## Consequência

Não registrada além do contexto.
