# 050. Pelo menos uma vez, sem deduplicar no worker

- **Data:** 2026-10-02
- **Status:** ativa

## Contexto

Duplicar um e-mail raro é aceitável e deduplicar exigiria banco ou Redis no worker.

## Decisão

Pelo menos uma vez, sem deduplicar no worker.

## Consequência

Não registrada além do contexto.
