# 065. No app do motorista, 409 de uma repetição conta como sucesso se o status já é o pedido

- **Data:** 2026-10-02
- **Status:** ativa

## Contexto

Com sinal ruim, o primeiro envio pode chegar e a resposta não; o motorista toca de novo e não deve ver erro.

## Decisão

No app do motorista, 409 de uma repetição conta como sucesso se o status já é o pedido.

## Consequência

Não registrada além do contexto.
