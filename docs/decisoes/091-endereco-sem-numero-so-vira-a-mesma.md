# 091. Endereço sem número só vira a mesma parada quando está no mesmo ponto do mapa

- **Data:** 2026-10-07
- **Status:** ativa

## Contexto

Sítios numa estrada têm o mesmo CEP e a mesma rua, mas ficam longe um do outro.

## Decisão

Endereço sem número só vira a mesma parada quando está no mesmo ponto do mapa.

## Consequência

Não registrada além do contexto.
