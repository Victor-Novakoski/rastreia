# 021. `failed` exige observação; `delivered` é final

- **Data:** 2026-10-01
- **Status:** ativa

## Contexto

O motivo da falha é o que a transportadora precisa para agir; voltar de `delivered` seria corrigir dado, não um evento.

## Decisão

`failed` exige observação; `delivered` é final.

## Consequência

Não registrada além do contexto.
