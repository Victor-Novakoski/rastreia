# 095. Busca ao apertar Enter, não a cada tecla

- **Data:** 2026-10-07
- **Status:** ativa

## Contexto

Uma chamada por busca; apagar o campo volta para a lista inteira na hora.

## Decisão

Busca ao apertar Enter, não a cada tecla.

Alternativas descartadas: busca com debounce, que dispara chamadas no meio da digitação.

## Consequência

Não registrada além do contexto.
